### 📝 四大可複製範本

---

#### 範本 A：最小可行版

```yaml
---
name: my-skill-name
description: 這技能做 X。當使用者要求 [觸發短語] 時使用。
---
```

**使用時機**：自用、實驗、快速原型

---

#### 範本 B：開源分發版

```yaml
---
name: my-awesome-skill
description: 做某件很棒的事。當使用者說「做 X」或
  上傳 .abc 檔案時使用。
license: MIT
metadata:
  author: Your Name
  version: 1.0.0
  documentation: https://github.com/you/repo
  support: support@example.com
---
```

**使用時機**：想發布到 GitHub、讓社群使用

---

#### 範本 C：MCP 強化版

```yaml
---
name: service-skill
description: 透過 [服務] MCP 伺服器處理 [任務]。
  當使用者提到「[觸發詞 1]」、「[觸發詞 2]」時使用。
  包含錯誤處理與最佳實踐。
license: Apache-2.0
compatibility: 需要 [服務] MCP 伺服器連線；API key 已設定
metadata:
  author: Your Company
  version: 2.1.0
  mcp-server: service-mcp-server
  category: workflow-automation
  tags: [service-name, automation, workflow]
---
```

**使用時機**：搭配自家 MCP 伺服器、加值給使用者

---

#### 範本 D：企業級完整版

```yaml
---
name: enterprise-workflow
description: 端到端企業工作流自動化。
  處理：專案建立、任務指派、通知發送、合規檢查。
  當使用者說「啟動新客戶」、「建立企業專案」時使用。
  【不要】用於個人任務管理。
license: proprietary
allowed-tools: "Bash(python:*) WebFetch"
compatibility: 需要 Python 3.10+、合規 API 存取、
  Linear MCP 與 Slack MCP 連線
metadata:
  author: Platform Engineering Team
  version: 3.2.0
  mcp-server: enterprise-platform-mcp
  category: enterprise-automation
  tags: [enterprise, compliance, workflow]
  documentation: https://docs.company.com/skills/enterprise-workflow
  support: platform-team@company.com
  changelog: https://docs.company.com/skills/enterprise-workflow/changelog
---
```

**使用時機**：組織部署、合規需求、多團隊共用

### 💡 模式組合參考

---

#### 🎨 組合 1：「發佈流水線」型

```
┌──────────────────────────────────────────────────┐
│                                                   │

│                                                   │
│  主模式：Pattern 2 (Multi-MCP)                    │
│  輔助 1：Pattern 1 (每階段內部用 Sequential)      │
```
