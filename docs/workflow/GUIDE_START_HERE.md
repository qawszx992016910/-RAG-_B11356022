## 💡 核心概念速記

### 四句咒語

```
📋 /specify  — 先說清楚要做什麼
🔍 /clarify  — 把模糊的地方問清楚
🗺️  /plan    — 畫一張施工藍圖
🔨 /implement— 按圖施工，步步驗證
```

### 三個字母法

```
SDD（規格驅動）← 定義「做什麼」
BDD（行為驅動）← 驗證「對不對」
TDD（測試驅動）← 確保「品質」
```

### 三種工作流

```
Lite（0-2 分）    ← 快，簡單
Standard（3-5 分） ← 平衡
Full（6+ 分）     ← 詳細，複雜
```

## 📞 常見問題（快速版）

### Q: 我應該讀所有章節嗎？

**A:** 不必。
- 新手：讀 Ch1-4 + 實戰章節
- 經驗者：直接用參考指南
- 遇到問題：讀 Ch8 相應陷阱

### Q: 我可以只用參考指南嗎？

**A:** 可以，但會事倍功半。
- 參考指南有範本，但沒有說明
- 最好先讀相應章節，再用參考指南

### Q: 這套流程對 Agent 一定有效嗎？

**A:** 95% 的情況有效。
- 前 5% 可能需要調整
- 但基本流程是可靠的

### Q: 可以和我的團隊分享嗎？

**A:** 可以。歡迎分享、列印、改編。
