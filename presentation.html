01 · 動機與問題定義
為什麼要做韓文學習 Bot？
學習痛點
  • 現有 App 缺乏自然語言互動
  • 字典無法解釋文法句型
  • 無法即時練習對話
  • TOPIK 備考缺乏模擬出題
解決方案
  • LINE Bot 零學習成本，直接提問
  • RAG 知識庫提供精確文法說明
  • 8 個專業 Skill 覆蓋各學習需求
  • APScheduler 每日推播韓文
目標使用者
  • 台灣韓文初學者 / 自學者
  • 備考 TOPIK 初級考生
  • 韓劇 / 韓流文化愛好者
  • 需要快速查字的學生
💡
核心問題
如何讓韓文初學者透過自然語言問答，隨時獲得準確的單字查詢、文法說明與 TOPIK 練習題，而不需要切換多個 App？

10 · 後台驗證
Hybrid RAG 檢索機制驗證
Hybrid + RRF 公式（兩階段）
① 每 seed Hybrid 分數
combined = 0.7 × cosine + 0.3 × BM25
② Multi-seed RRF 融合
scorerrf = Σ 1 / (60 + ranki)
cosine (0.7)：語意相似度 · BM25 (0.3)：關鍵詞搜索
RRF 跨多 seed 排名融合，鈍化極端分數
→ 避免純 vector 遇冷門詞失效
Multi-seed 查詢
  • 原始問題 + 分解子問題各別查詢
  • 合併結果後 RRF 重新排序
  • Top-4 chunks 傳給 generator（final_context_k=4）

⚠️ 限制

  • 不支援多輪對話記憶，每次問答獨立無上下文
🔧 遇到的問題與解法
問題原因解決方式
品質警告出現在所有 skill judge 不分 skill 類型一律審查 加入 SKIP_JUDGE_SKILLS
易混淆詞顯示同義詞 SKILL.md 規則不明確，同義詞被誤判為易混淆 規則：발음相近才算易混淆
Router 意圖誤判 keyword 清單含歧義詞「什麼意思」 移除 TRANSLATE_TO_ZH 歧義詞
grammar_guide 生成生硬例句 文法 chunk 混入詞彙 chunk，機械式拼湊 SKILL.md 規則 + category filter 鎖定 grammar_patterns
APScheduler date filter 無效 SQL 表達式在 Python 層執行無效 Python 計算 cutoff ISO timestamp
Chunk 混入無關內容 Router 未強制鎖定 rag_categories Router 強制 + SKILL.md 兜底過濾
