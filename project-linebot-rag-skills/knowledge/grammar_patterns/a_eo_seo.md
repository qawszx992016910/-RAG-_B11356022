# 아/어서

## 基本形式

**V/A + 아서/어서**

- 語幹母音為 ㅏ/ㅗ → **아서**
- 其他母音 → **어서**
- 하다 → **해서**

## 用途

### 1. 原因/理由（因為）

前句是後句的原因。後句不能用命令句或勸誘句。

- 배가 고파서 밥을 먹었어요。（因為肚子餓，所以吃了飯。）
- 비가 와서 집에 있었어요。（因為下雨，所以待在家。）
- 피곤해서 일찍 잤어요。（因為累，所以早睡了。）

### 2. 順序（然後）

表示動作依序發生。

- 손을 씻어서 밥을 먹어요。（洗手之後吃飯。）
- 시장에 가서 채소를 샀어요。（去了市場，買了蔬菜。）

## 注意事項

- 아/어서 不能用於命令句/勸誘句（用 으니까 代替）
- ✗ 늦어서 빨리 와요 → ✅ 늦으니까 빨리 와요

## 與 으니까 的差異

| | 아/어서 | 으니까 |
|---|---|---|
| 命令/勸誘句 | ✗ | ✅ |
| 說話者主觀判斷 | 弱 | 強 |
