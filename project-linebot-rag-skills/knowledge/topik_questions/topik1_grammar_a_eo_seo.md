# TOPIK I 文法題 - 아/어서

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。

배가 고파요. 그래서 빨리 집에 ( )。

A. 가고 싶어요
B. 가서 먹었어요
C. 가니까 좋아요
D. 갔지만 없었어요

**正確答案：A**

**解析：**
- **가고 싶어요（想回家）**：배가 고파서 빨리 집에 가고 싶다는 뜻으로 자연스러워요 ✅
- 가서 먹었어요：「집에 가서 먹었어요」는 完成式，但這裡需要表達「想」的意思 ✗
- 가니까 좋아요：語意不通，回家不等於「很好」 ✗
- 갔지만 없었어요：「去了但不在」語意不符 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

비가 ( ) 우산을 가져왔어요。

A. 오니까
B. 와서
C. 오지만
D. 오면

**正確答案：B**

**解析：**
- **와서（下雨所以）**：아/어서 表示因果，下雨→帶傘 ✅
- 오니까：同是因果但偏主觀判斷，「비가 와서」更自然 ✗
- 오지만：表轉折（下雨但是…），語意不符 ✗
- 오면：表假設（如果下雨），但已是過去完成動作 ✗
