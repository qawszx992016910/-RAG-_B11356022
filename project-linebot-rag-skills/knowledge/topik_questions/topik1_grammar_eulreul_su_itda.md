# TOPIK I 文法題 - (으)ㄹ 수 있다/없다

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。

저는 수영을 ( )。

A. 할 수 있어요
B. 하고 싶어요
C. 해야 해요
D. 하지 마세요

**正確答案：A**

**解析：**
- **할 수 있어요（能游泳）**：(으)ㄹ 수 있다 表示能力 ✅
- 하고 싶어요：想游泳，表願望 ✗（題目問能力）
- 해야 해요：必須游泳，表義務 ✗
- 하지 마세요：不要游泳，表禁止 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

오늘은 너무 바빠서 약속을 ( )。

A. 지킬 수 없어요
B. 지켜야 해요
C. 지키고 싶어요
D. 지키지 마세요

**正確答案：A**

**解析：**
- **지킬 수 없어요（沒辦法守約）**：太忙→沒能力守約，(으)ㄹ 수 없다 表「無法」 ✅
- 지켜야 해요：應該守約，與「太忙」矛盾 ✗
- 지키고 싶어요：想守約，語意方向不符 ✗
- 지키지 마세요：不要守約，意思不對 ✗
