# TOPIK I 文法題 - 고 싶다

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。

한국에 ( ) 열심히 공부해요。

A. 가고 싶어서
B. 가니까
C. 가지만
D. 가면서

**正確答案：A**

**解析：**
- **가고 싶어서（因為想去韓國）**：「고 싶다＋아/어서」表示願望是原因 ✅
- 가니까：語感偏主觀理由，比較不自然 ✗
- 가지만：轉折，表「去韓國但努力讀書」，邏輯矛盾 ✗
- 가면서：同時進行，「去的同時讀書」語意不對 ✗
