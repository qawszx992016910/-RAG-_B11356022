# TOPIK I 敬語題 - 경어 기초

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。

할머니가 지금 방에 ( )。

A. 있어요
B. 계세요
C. 있으세요
D. 계요

**正確答案：B**

**解析：**
- **계세요（在/敬語）**：對長輩，있다的敬語是 **계시다** ✅
- 있어요：一般語，對長輩不禮貌 ✗
- 있으세요：잘못된 형태（錯誤形態）✗
- 계요：活用錯誤，正確是 계세요 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

선생님, 점심을 ( )?

A. 먹었어요
B. 드셨어요
C. 잡수었어요
D. 먹으셨어요

**正確答案：B**

**解析：**
- **드셨어요（吃了嗎/敬語過去）**：먹다의 敬語는 드시다，過去形은 드셨어요 ✅
- 먹었어요：一般語，對老師不禮貌 ✗
- 잡수었어요：잡수시다 也是敬語但較古老，드시다更常用 ✗
- 먹으셨어요：活用錯誤形態 ✗
