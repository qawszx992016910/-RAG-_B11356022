# TOPIK I 語彙題

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。
（請選出括號中適合的詞。）

학교에 ( ).

A. 갑니다
B. 먹습니다
C. 잡니다
D. 읽습니다

**正確答案：A**

**解析：**
- 갑니다（去）→ 學校에 갑니다（去學校）✅
- 먹습니다（吃）→ 不能「吃學校」✗
- 잡니다（睡）→ 語意不通 ✗
- 읽습니다（讀）→ 需要接書/文章等 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

저는 한국어를 ( ).

A. 마십니다
B. 배웁니다
C. 입습니다
D. 탑니다

**正確答案：B**

**解析：**
- 배웁니다（學習）→ 한국어를 배웁니다（學韓文）✅
- 마십니다（喝）→ 需要接飲料 ✗
- 입습니다（穿）→ 需要接衣服 ✗
- 탑니다（搭乘）→ 需要接交通工具 ✗
