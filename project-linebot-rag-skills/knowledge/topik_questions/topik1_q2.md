# TOPIK I 文法題

## 題目 1

다음 밑줄 친 부분과 같은 의미를 고르세요。
（請選出與底線部分意思相同的選項。）

저는 학생**이에요**.

A. 이다
B. 이어요
C. 입니다
D. 이고

**正確答案：C**

**解析：**
- 이에요 = 이다（是）的 해요체（非正式禮貌）
- 입니다 = 이다 的 합쇼체（正式禮貌）→ 意思相同 ✅
- 이고 = 連接語尾，意思不同 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

가: 이것이 가방이에요?
나: 아니요, 가방( ) 아니에요.

A. 이
B. 가
C. 은
D. 을

**正確答案：A**

**解析：**
- 가방 + 이 아니에요 → 가방이 아니에요（不是包包）
- 가방 有收音 ㅇ → 接 **이** ✅
- 無收音則接 **가**（예: 의자가 아니에요）
