# TOPIK I 語彙題 - 時間詞

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。

오늘은 월요일이에요. ( )은 화요일이에요。

A. 어제
B. 내일
C. 모레
D. 아까

**正確答案：B**

**解析：**
- **내일（明天）**：오늘（今天）月曜日，내일（明天）= 火曜日 ✅
- 어제（昨天）：昨天是上週日 ✗
- 모레（後天）：後天是水曜日 ✗
- 아까（剛才）：아까 是「剛才」，不能接「이다」 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

지금 시험이 없어요. ( ) 시험이 있어요。

A. 이따가
B. 아까
C. 방금
D. 지난

**正確答案：A**

**解析：**
- **이따가（待會兒）**：現在沒考試，待會兒有考試 ✅
- 아까（剛才）：已過去，「剛才有考試」但現在「지금 없다」矛盾 ✗
- 방금（剛剛）：剛剛，指極近的過去 ✗
- 지난（上次的）：지난 要接「주」「달」等，不能單獨使用 ✗
