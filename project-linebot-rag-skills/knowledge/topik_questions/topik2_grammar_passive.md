# TOPIK II 文法題 - 피동（被動）

## 題目 1

다음 ( ) 안에 알맞은 것을 고르세요。

도둑이 경찰에게 ( )。

A. 잡았어요
B. 잡혔어요
C. 잡아요
D. 잡히세요

**正確答案：B**

**解析：**
- **잡혔어요（被抓了）**：피동（被動）形態，도둑（小偷）是被抓的對象 ✅
- 잡았어요：主動形，「（我）抓了」，主語不對 ✗
- 잡아요：主動現在式 ✗
- 잡히세요：被動+敬語，도둑不需用敬語 ✗

## 題目 2

다음 ( ) 안에 알맞은 것을 고르세요。

이 문이 바람에 ( )。

A. 열었어요
B. 열려요
C. 열어요
D. 열렸어요

**正確答案：D**

**解析：**
- **열렸어요（被打開了）**：被動過去式，門被風打開了 ✅
- 열었어요：主動過去式，「（我/他）打開了」 ✗
- 열어요：主動現在式 ✗
- 열려요：被動現在式，但過去事件要用過去式 ✗
