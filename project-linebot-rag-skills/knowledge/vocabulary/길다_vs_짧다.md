# 길다 / 짧다

**品詞：** 형용사（形容詞）

**意思：** 길다：長　짧다：短

## 발음（發音）

길다 [gil-da]　짧다 [jjalp-da]

## 例句

- 머리카락이 길어요。（頭髮很長。）
- 길고 긴 여행이었어요。（是一段很長的旅程。）
- 치마가 짧아요。（裙子很短。）
- 짧은 시간에 많이 배웠어요。（在短時間內學了很多。）
