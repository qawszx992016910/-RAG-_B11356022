# 높다 / 낮다

**品詞：** 형용사（形容詞）

**意思：** 높다：高　낮다：低

## 발음（發音）

높다 [nop-da]　낮다 [nat-da]

## 例句

- 산이 매우 높아요。（山非常高。）
- 목소리가 높아요。（聲音很高。）
- 가격이 낮아요。（價格很低。）
- 의자가 너무 낮아요。（椅子太低了。）
