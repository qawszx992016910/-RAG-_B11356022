# 다르다 (다르다)

**品詞：** 형용사（形容詞）

**意思：** 不同、有差異

## 活用

- 달라요（해요체）/ 다릅니다（합쇼체）

## 例句

- 우리는 생각이 달라요。（我們想法不同。）
- 한국어와 일본어는 달라요。（韓文和日文不同。）
- 뭐가 달라요?（有什麼不同？）

## 易混淆詞

**다르다 vs 틀리다**
- **다르다** = 不同（中性：兩者各有不同）
- **틀리다** = 錯誤（有對錯之分）

例：
- 내 생각과 달라요。（和我想法不同。）← 沒有對錯
- 이 답은 틀렸어요。（這個答案錯了。）← 有對錯
