# 맞추다 (맞추다)

**品詞：** 동사（動詞）

**意思：** 對準、配合、拼湊、訂製

## 例句

- 퍼즐을 맞춰요。（拼拼圖。）
- 시간을 맞춰요。（配合時間。）
- 정답을 맞춰요。（猜答案。）
- 양복을 맞췄어요。（訂製了西裝。）

## vs 맞다

- **맞다**：是對的（狀態）
- **맞추다**：去配合、去拼（動作）
