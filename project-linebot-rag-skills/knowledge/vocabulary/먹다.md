# 먹다 (먹다)

**品詞：** 동사（動詞）

**意思：** 吃

## 活用

- 먹어요（해요체）/ 먹습니다（합쇼체）
- 먹었어요（吃了）
- 먹고 싶어요（想吃）

## 例句

- 밥을 먹어요。（吃飯。）
- 뭐 먹고 싶어요?（想吃什麼？）
- 아침을 먹었어요。（吃了早餐。）
- 맵게 먹어요。（吃辣的。）
