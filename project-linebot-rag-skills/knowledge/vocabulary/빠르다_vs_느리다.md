# 빠르다 / 느리다

**品詞：** 형용사（形容詞）

**意思：** 빠르다：快　느리다：慢

## 발음（發音）

빠르다 [ppa-reu-da]　느리다 [neu-ri-da]

## 易混淆詞

⚠️ **빠르다（快）vs 느리다（慢）**：
- 빠른 버스를 타요。（搭快車。）
- 느린 음악을 좋아해요。（喜歡慢的音樂。）

## 例句

- 기차가 매우 빨라요。（火車非常快。）
- 빠른 결정이 필요해요。（需要快速的決定。）
- 이 시계는 좀 느려요。（這個時鐘慢了一點。）
- 거북이는 느려요。（烏龜很慢。）
