# 쓰다

**品詞：** 동사／형용사（動詞／形容詞）

**意思：** ① 寫　② 用／使用　③ 苦（味道）　④ 戴（帽子）

## 발음（發音）

쓰다 [sseu-da]

## 易混淆詞

⚠️ **쓰다**：四個常見意思，靠語境區分。
- 글을 써요。（寫文章。）→ 寫
- 돈을 써요。（花錢。）→ 使用
- 이 약은 써요。（這藥很苦。）→ 苦
- 모자를 써요。（戴帽子。）→ 戴

## 例句

- 편지를 쓰고 있어요。（正在寫信。）
- 이 컴퓨터를 써도 돼요?（可以用這台電腦嗎？）
- 이 김치는 너무 써요。（這泡菜太苦了。）
- 모자를 쓰면 귀여워요。（戴帽子很可愛。）
