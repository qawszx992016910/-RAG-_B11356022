# 어렵다 / 쉽다

**品詞：** 형용사（形容詞）

**意思：** 어렵다：難　쉽다：容易

## 발음（發音）

어렵다 [eo-ryeop-da]　쉽다 [swip-da]

## 例句

- 한국어 문법이 어려워요。（韓文文法很難。）
- 이 문제는 어렵지 않아요。（這題不難。）
- 이 일은 쉬워요。（這件事很容易。）
- 쉬운 방법을 찾아요。（找簡單的方法。）
