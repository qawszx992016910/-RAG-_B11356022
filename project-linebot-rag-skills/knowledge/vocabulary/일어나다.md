# 일어나다 (일어나다)

**品詞：** 동사（動詞）

**意思：** 起床、起身、站起來

## 活用

- 일어나요（해요체）/ 일어납니다（합쇼체）
- 일어났어요（起床了）

## 例句

- 아침 7시에 일어나요。（早上7點起床。）
- 일어나세요!（起床！）
- 의자에서 일어났어요。（從椅子上站起來了。）
