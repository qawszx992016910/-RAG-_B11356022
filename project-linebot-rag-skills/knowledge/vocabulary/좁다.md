# 좁다 (좁다)

**品詞：** 형용사（形容詞）

**意思：** 窄、狹小

## 活用

- 좁아요（해요체）/ 좁습니다（합쇼체）

## 例句

- 방이 좁아요。（房間很窄。）
- 길이 좁아서 못 지나가요。（路太窄過不去。）
- 이 옷이 좁아요。（這衣服太窄了。）

## 反義詞

좁다（窄）↔ 넓다（寬、寬廣）
