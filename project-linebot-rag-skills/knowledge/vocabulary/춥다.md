# 춥다 (춥다)

**品詞：** 형용사（形容詞）

**意思：** 冷（天氣或氣溫）

## 活用

- 추워요（해요체）/ 춥습니다（합쇼체）
- 추웠어요（曾經很冷）

## 例句

- 오늘 너무 추워요。（今天太冷了。）
- 겨울이라서 추워요。（因為是冬天所以冷。）
- 한국 겨울은 정말 춥습니다。（韓國的冬天真的很冷。）

## 注意

**춥다 vs 차갑다**
- **춥다** = 天氣冷（環境溫度）
- **차갑다** = 東西冷（物體溫度）

例：
- 날씨가 추워요。（天氣冷。）
- 물이 차가워요。（水很冷。）
