# 틀리다 (틀리다)

**品詞：** 동사（動詞）

**意思：** 錯誤、不對

## 例句

- 이 답이 틀렸어요。（這個答案錯了。）
- 계산이 틀렸어요。（計算錯了。）
- 틀려도 괜찮아요。（錯了也沒關係。）

## 易混淆詞

**틀리다 vs 다르다**
- **틀리다** = 錯誤（對 vs 錯）
- **다르다** = 不同（A ≠ B，但兩個都對）
